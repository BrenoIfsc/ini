# Detecção automática de (potenciais) fatores no texto fonte contribuindo para o viés de gênero na tradução automática

## Abstrato
Esse projeto de pesquisa busca desenvolver uma metodologia abrangente para ajudar sistemas de tradução automática (TA) terem mais inclusão de gênero para a sociedade. 
O objeto é a criação de um sistema de detecção, um modelo de aprendizado de máquina (AM) treinado a partir de anotações manuais, que consegue analisar o dado fonte e destacar palavras e frases que influênciam o viés de gênero na tradução esperada.
Os principais resultados da pesquisa serão (1) uma amostra de dados anotados manualmente, (2) uma taxonomia, e (3) um modelo.
